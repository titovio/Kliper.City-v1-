# Kliper.City — scrollytelling demo

Готовый статический прототип: город приближается по скроллу, затем раскрывается story, затем появляется карточка объекта.

## Как открыть
Откройте `index.html` в браузере.

## Как менять объекты
Откройте `script.js` и измените массив `places`: название, тип, район, текст истории, метрики и координаты точки.

## Что внутри
- `index.html` — структура страницы
- `styles.css` — визуальный стиль по ORYZO AI / Refero design tokens
- `script.js` — логика scroll animation и массив объектов
- `DESIGN.md` — полный присланный style reference для Codex / Claude / Cursor

## Как отдать Codex
Передайте весь архив и задачу: “Интегрируй этот scrollytelling-компонент в Kliper.City, сохрани текущую навигацию и адаптируй массив places под реальные ЖК/районы/компании.”
