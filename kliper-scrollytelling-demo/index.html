как внедрять

Один файл данных — много сцен

В script.js есть массив places. Для каждого объекта задаются название, тип, район, текст истории, метрики и позиция точки на карте. Компонент сам создаёт полный сценарий: город → приближение → история → карточка.

В реальном сайте вместо CSS-карты можно подставить изображение города, SVG-карту, 2ГИС-скрин или WebGL-сцену. Логика скролла останется такой же.
