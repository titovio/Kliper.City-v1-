# Kliper.City: regression checklist

Этот чеклист нужен после любых значимых правок.

## Быстрая проверка

| № | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Открыть `/index.html` | сайт загружается без зависания | не проверено |
| 2 | Переключить светлую/темную тему | тема меняется, текст читается | не проверено |
| 3 | Открыть `Застройщики` | карточки видны, счетчик корректный | не проверено |
| 4 | Открыть `Новостройки` | карточки ЖК видны | не проверено |
| 5 | Открыть `Готовые ЖК` | выдача не пустая без причины | не проверено |
| 6 | Открыть `Для бизнеса` | бизнес-карточки и фильтры видны | не проверено |
| 7 | Применить фильтр | счетчик меняется, selected tag появляется | не проверено |
| 8 | Сбросить фильтр | выдача возвращается | не проверено |
| 9 | Открыть карточку | появляется быстрый просмотр/страница | не проверено |
| 10 | Поставить лайк | состояние сохраняется локально | не проверено |
| 11 | Открыть профиль `Мария` | профиль открывается | не проверено |
| 12 | Открыть stories | viewer открывается и закрывается | не проверено |
| 13 | Проверить mobile 390px | нет горизонтального overflow | не проверено |
| 14 | Проверить консоль | нет новых ошибок от измененных файлов | не проверено |

## Расширенная проверка

### Header

- Логотип возвращает на главную.
- Кнопка темы работает.
- Кнопка профиля открывает страницу пользователя.
- Stories не перекрывают header.

### Каталог

- Вкладки работают независимо.
- Счетчик совпадает с выдачей.
- Grid/list/map переключатели не ломают карточки.
- Empty-state выглядит корректно в светлой и темной теме.

### Фильтры

- Dropdown открывается.
- Выбор применяет фильтр.
- Selected tag появляется рядом со счетчиком.
- `Сбросить` очищает фильтры.
- Mobile-фильтры не перекрывают карточки.

### Карточки

- Название видно.
- Статусы/теги читаются.
- Лайк, подписка, рецензии одинакового размера, если это актуальное правило.
- Клик по карточке не зависает.

### Stories

- Большой режим по умолчанию.
- Малый режим при скролле вниз.
- Возврат большого режима по правилу текущей версии.
- Viewer открывается.
- Viewer закрывается.
- Нет старых цветных слоев.

### Профиль

- `Мария` открывается.
- Лайкнутые карточки попадают в профиль.
- Вкладки профиля не ломают layout.
- Чаты/друзья не создают горизонтальный overflow.

### Бизнес

- Фильтры бизнеса визуально совпадают с общим стилем.
- Выбранные теги появляются рядом со счетчиком.
- Сброс работает.
- Темная тема не закрашивает контейнеры неправильно.

### Motion

- `window.Motion` существует.
- `window.KLIPER_MOTION` существует.
- Нет ошибок `motion.global.js`.
- Нет массовых анимаций без задачи.

## Минимальные команды

Для измененных JS-файлов:

```powershell
& 'C:\Users\oxv20\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' --check 'path\to\file.js'
```

В корне проекта не запускать `npm build`, пока нет корневого `package.json`.
