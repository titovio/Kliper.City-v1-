# Kliper.City v1: паспорта страниц

## 1. Главная оболочка

Назначение: общий вход в сайт, бренд, истории, навигация и каталог.

Где находится:

- `index.html`
- `js/app.js`
- `css/style.css`
- `css/ui-ux-pro-max.css`
- `css/story-categories.css`

Блоки:

- header;
- логотип;
- кнопка темы;
- кнопка профиля;
- истории;
- навигационные кнопки;
- поиск;
- фильтры;
- каталог;
- переключатель вида;
- кнопка "Наверх".

Функции:

- переход на главную;
- переключение темы;
- открытие профиля;
- открытие stories;
- поиск;
- фильтрация;
- переключение сетка/список/карта.

Риски:

- нельзя ломать `#root`;
- нельзя без проверки менять тексты и `aria-label` ключевых кнопок;
- нельзя менять порядок подключений данных и app без проверки.

## 2. Каталог застройщиков

Назначение: показать застройщиков/компании и дать пользователю быстрые действия.

Где находится:

- `js/app.js`
- `js/data/developers.js`
- `js/catalog/developer-cards.js`
- `js/catalog/developer-card-badges.js`
- `js/catalog/developer-cover-overrides.js`

Блоки:

- счетчик карточек;
- фильтры;
- легенда строится/отстроено;
- карточки;
- кнопки лайка, подписки, рецензий;
- модальное окно карточки;
- большая страница компании.

Функции:

- лайк - работает локально;
- подписка - работает локально;
- рецензия - работает локально/частично;
- открытие карточки - работает;
- переход на большую страницу - работает;
- сортировка - работает внутри app;
- фильтрация - работает, но зависит от общего механизма.

Риски:

- структура карточки используется сторонними модулями;
- `aria-label^="Открыть карточку"` является важным крючком;
- статусные бейджи и легенда завязаны на данные `activeJK`/`builtJK`.

## 4. Готовые ЖК

Назначение: показать готовые или сданные жилые комплексы.

Где находится:

- `js/app.js`
- `js/data/buildings.js`

Статус: есть как режим каталога, но точность зависит от данных. В данных не всегда явно используется статус "сдан", встречаются "строится" и "уточнить".

Что уточнить:

- какие значения статуса считаются готовыми;
- должны ли "готовые ЖК" использовать отдельный массив или фильтр общего массива.
