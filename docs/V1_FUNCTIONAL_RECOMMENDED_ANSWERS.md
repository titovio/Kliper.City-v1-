## Итог Architect / Main

Рекомендуемый вектор:

```text
Функции v1 утверждаем как каталог + социальная витрина + кабинет компании prototype.
Рабочие server функции, admin, auth, CRM, оплаты, role profiles и advanced privacy идут после functional v1 audit и data model.
```

После утверждения владельцем создать:

- `V1_FUNCTIONAL_DECISIONS.md`;
- `V1_PAGE_COMPLETION_MATRIX.md`;
- задачи чатам на functional gap audit;
- admin/backend requirements pack.
