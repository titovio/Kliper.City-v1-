# ROLE-PROFILES owner brief

Дата: 2026-07-07.

Статус: краткий бриф для владельца перед любыми задачами реализации. Код, CSS, JS, HTML и `js/app.js` не менялись.

Полная модель: `docs/ROLE_PROFILES_SCOPE.md`.

## 1. Что предлагаем

Добавить в будущую модель Kliper.City ролевые профили поверх одного пользовательского аккаунта.

Обычный пользователь остается бесплатным и не становится медиа-автором. Он создает ценность через:

- лайки;
- теги любимого;
- подписки;
- рецензии-рекомендации.

Ролевой пользователь покупает отдельный тариф и получает инструменты публичного профессионального присутствия:

- карточку роли;
- публикации;
- stories;
- ролевые подборки;
- внешние ссылки;
- базовую статистику.

## 2. Главная продуктовая логика

```text
Обычный пользователь создает сарафанное радио.
Ролевой пользователь создает публичный контент.
Компания создает официальные материалы.
Kliper маркирует роли, связи и актуальность.
Рейтинг строится на доверии, а не на оплате.
```

## 3. Что важно не перепутать

Обычный пользователь не публикует новости и не ведет stories.

Вместо этого он раскладывает любимое по тегам:

- `Люблю гулять`;
- `Лучшая еда`;
- `Куда сходить с детьми`;
- `Красивые дворы`;
- `Хочу посмотреть`;
- `ЖК для жизни`;
- `Для бизнеса`;
- `Места для выходных`.

Эти теги становятся сигналами для карточек и мягких рейтингов.

## 4. Рецензии

Рецензия - это не отзыв и не жалоба. Это рекомендация: чем место, компания, район или объект понравились.

Верх карточки должен показывать лучшие рецензии-рекомендации:

- свежие;
- подтвержденные;
- с понятной ролью автора;
- без скрытого конфликта интересов;
- с актуальным статусом рекомендации.

Имя автора может быть скрыто, но контекст должен быть виден:

```text
Пользователь
Житель района
Риэлтор
Автор обзоров
Специалист
Представитель компании
```

Если есть профессиональная связь с темой, нужен двойной тег:

```text
Житель района / Риэлтор
Пользователь / Риэлтор
Пользователь / Специалист
Житель района / Представитель компании
```

## 5. Тариф физлица

Рабочая гипотеза:

```text
Профиль автора
990 ₽ / мес
```

Это отдельный тариф, не B2B-тариф компании.

Тариф дает инструменты:

- 1 публичную карточку роли;
- публикации;
- stories;
- ролевые подборки;
- внешние ссылки;
- базовую статистику;
- привязки к районам, ЖК, компаниям или категориям.

Тариф не дает:

- официальный статус компании;
- CRM;
- заявки;
- покупку органического рейтинга;
- скрытие коммерческой связи;
- покупку статуса `Эксперт`.

## 6. Если пользователь перестал платить

Профиль не удаляется.

Правило:

```text
Оплата покупает активное присутствие, а не личность и не историю.
```

Остается:

- ролевой профиль;
- история;
- рецензии;
- роль;
- верификация, если правила не нарушены;
- доступ по прямой ссылке.

Отключается:

- новые stories;
- новые профессиональные публикации;
- продвижение;
- расширенная карточка;
- приоритет в списках специалистов;
- расширенная статистика.

Рабочая гипотеза:

- 0-7 дней после неоплаты: grace period;
- 8-60 дней: базовый специалист;
- после 60 дней: неактивный профиль, доступен по прямой ссылке.

## 7. Что входит в v1/v2/v3

v1:

- обычный профиль;
- лайки;
- подписки;
- рецензии;
- продуктовая фиксация модели.

Финал v1 после backend/auth:

- серверные рецензии;
- visibility;
- moderation status;
- даты создания/обновления;
- verification status;
- база для тегов любимого.

v2:

- ролевые профили;
- тариф автора;
- stories от авторов;
- публикации;
- ролевые подборки;
- двойные теги;
- верификация ролей;
- форматы список/карта.

v3:

- travel creators;
- события;
- билеты;
- гиды;
- услуги;
- marketplace специалистов;
- расширенное продвижение.

## 8. Решения владельца

Нужно подтвердить перед любыми задачами реализации:

1. Название тарифа: `Профиль автора`, `Профиль эксперта`, `Профессиональный профиль` или другое.
2. Цена стартового тарифа физлица: оставляем гипотезу `990 ₽ / мес` или меняем.
3. Стартовые роли: `Риэлтор`, `Автор обзоров`, `Специалист`, `Представитель компании`.
4. Первый набор тегов любимого.
5. Можно ли пользователю создавать свои теги или только выбирать из стандартных.
6. Минимальная верификация для покупки ролевого тарифа.
7. Правила после неоплаты: 7 дней grace, 60 дней basic, потом inactive.
8. Стартовые форматы ролевых подборок: список и карта.
9. Подтверждаем ли правило: статус `Эксперт` нельзя купить.
10. Когда это обсуждать как реализацию: финал v1 после backend/auth или v2.
