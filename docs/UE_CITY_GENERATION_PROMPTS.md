# UE City Generation Prompts

Цель: быстро собрать городскую сцену Kliper.City в Unreal Engine через связку AI-агентов. Первый промт задает структуру города и данные сцены, второй просит агента реализовать это в UE, отполировать визуал и подготовить cinematic-export.

Контекст текущего проекта:

- сайт и данные лежат в корне проекта Kliper.City;
- готовый motion-пайплайн находится в `kliper-motion/`;
- текущий storyboard городского интро: `kliper-motion/storyboard/tyumen-intro.md`;
- текущие keyframes: `kliper-motion/public/keyframes/`.

## Prompt 1: City Director

Используй этот промт в Claude/LLM как постановочное ТЗ. Результатом должен быть структурированный `SceneSpec`, который потом отдаётся Codex/UE-агенту.

```text
Ты выступаешь как city director и technical art director для Kliper.City.

Нужно спроектировать процедурную городскую сцену для Unreal Engine: современная Тюмень, река Тура, жилые районы, новые ЖК, дороги, зеленые дворы, мягкий премиальный real-estate стиль. Сцена должна подходить для 8-12 секундного интро сайта: облака -> город -> район -> подсвеченные объекты недвижимости -> абстрактный интерфейс Kliper.City.

Сделай не художественное описание, а технический SceneSpec для реализации в UE:

1. Общая карта:
   - размер сцены в метрах;
   - направление реки;
   - 4-6 районов;
   - основные дороги;
   - зоны плотной и средней застройки;
   - парки/дворы/набережная.

2. Набор объектов:
   - типы зданий: башни, квартальная застройка, малоэтажные дома, общественные здания;
   - параметры зданий: высота, ширина, цвет, материал, плотность окон;
   - дороги, мосты, деревья, дворы, парковки, световые property-nodes.

3. Правила генерации:
   - как расставлять здания вдоль дорог и у реки;
   - как избежать однообразной сетки;
   - как сохранить читаемый силуэт города с высоты;
   - как выделить 8-12 объектов недвижимости без рекламного перекоса в сторону одного ЖК.

4. Визуальный стиль:
   - утро, мягкая дымка, реалистичная архитектура, Lumen/Nanite-ready look;
   - палитра: светлый бетон, стекло, теплые окна, зеленые дворы, холодноватое небо;
   - никаких фейковых логотипов, читаемого псевдотекста, картографических UI-элементов и водяных знаков.

5. Камера:
   - 6 key shots для интро;
   - координаты/высота/фокусное расстояние для каждого shot;
   - что должно быть видно в кадре;
   - как камера переходит между кадрами.

6. Выход:
   - верни SceneSpec в JSON;
   - после JSON дай краткое объяснение, почему сцена будет хорошо работать для сайта недвижимости.

Ограничения:
- если точных ассетов нет, используй модульные placeholder-объекты, которые потом можно заменить;
- не используй чужие карты, спутниковые снимки или бренды как финальный визуал;
- структура должна быть пригодна для автоматической генерации через UE Python/Blueprint/PCG.
```

## Prompt 2: UE Implementation Agent

Используй этот промт в Codex/Claude с доступом к Unreal-проекту. Вставь после него `SceneSpec` из первого промта.

```text
Ты работаешь как Unreal Engine implementation agent внутри UE-проекта.

На входе у тебя SceneSpec ниже. Реализуй по нему процедурный город Kliper.City как отдельную сцену/level, не ломая существующие уровни проекта.

Задача:
1. Создай новый level: KliperCity_Procedural_Intro.
2. Создай или обнови генератор сцены:
   - предпочтительно UE Python Editor Utility или Blueprint/PCG graph;
   - генератор должен быть повторяемым: один seed -> одинаковый город;
   - все параметры вынеси в читаемый config/data asset.
3. Сгенерируй сцену:
   - плоскость/ландшафт;
   - река с набережной;
   - дорожная сеть;
   - районы;
   - здания разных типов;
   - деревья и дворы;
   - 8-12 мягких property-nodes без читаемого текста;
   - простая интерфейсная portal-зона для финального перехода в сайт.
4. Материалы:
   - создай базовые материалы для бетона, стекла, крыш, дорог, воды, зелени и световых nodes;
   - материалы должны выглядеть чисто в Lumen, без кислотных цветов.
5. Оптимизация:
   - используй instancing/HISM/ISM для повторяющихся зданий, деревьев и оконных модулей;
   - избегай тысяч отдельных Actor, если можно собрать инстансами;
   - сцена должна быть пригодна для cinematic preview в 1920x1080.
6. Камера и sequence:
   - создай Level Sequence KliperCity_Intro_12s;
   - длительность 12 секунд, 30 fps;
   - добавь 6 camera key poses из SceneSpec;
   - движение плавное: clouds/high altitude -> river/city -> district -> property nodes -> floating cards/portal.
7. Проверка:
   - открой level;
   - проверь, что сцена не пустая;
   - проверь, что здания стоят над землей, не пересекают реку хаотично, property-nodes видны с камеры;
   - проверь, что sequence проигрывается от начала до конца;
   - выведи список созданных файлов/ассетов.

Правила:
- не редактируй существующие production-levels без явного запроса;
- не скачивай внешние ассеты;
- если нужного ассета нет, используй Engine Basic Shapes и процедурные материалы;
- не добавляй читаемый фейковый текст в 3D-сцену;
- если API UE не позволяет сделать часть задачи автоматически, создай максимально близкий вариант и явно перечисли, что нужно доделать руками.

После реализации верни:
1. что создано;
2. где лежат файлы/ассеты;
3. как перегенерировать город с другим seed;
4. как экспортировать cinematic video;
5. короткий список оставшихся ручных улучшений.

SceneSpec:
<ВСТАВЬ JSON ИЗ PROMPT 1>
```

## Быстрый мост к текущему сайту

Если Unreal-сцена нужна как интро для сайта, экспортируй ролик из UE в MP4 и подключай его по уже принятому паттерну:

- desktop: `1920x1080`, H.264 MP4, 8-12 секунд;
- mobile: отдельный вертикальный кроп `1080x1920` или статичный poster;
- показывать интро один раз через `localStorage`;
- уважать `prefers-reduced-motion`;
- после конца видео открывать реальный интерфейс Kliper.City.

Если Unreal пока недоступен, ближайший рабочий путь уже есть в проекте: заменить или обновить keyframes в `kliper-motion/public/keyframes/`, затем использовать текущий storyboard и `npm run render:intro` внутри `kliper-motion/`.

## Acceptance Checklist

- Город читается с высоты и не выглядит как случайная россыпь коробок.
- Река, дороги и районы образуют понятную структуру.
- Есть 8-12 нейтральных property-nodes без рекламного перекоса.
- Камера проходит все 6 этапов интро без резких скачков.
- Нет фейкового текста, водяных знаков, чужих карт и лишнего UI.
- Экспортированный ролик можно безопасно встроить в сайт как intro overlay.
