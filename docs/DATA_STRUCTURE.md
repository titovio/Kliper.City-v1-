# Kliper.City v1: структура данных

## 1. Общая модель

Проект использует данные без backend. Основные массивы объявляются в JS-файлах как глобальные переменные `window.KLIPER_*`.

## 2. Настройки сайта

Файл: `js/data/site-config.js`

Содержит:

- название бренда;
- подзаголовок;
- путь к логотипу;
- имя пользователя по умолчанию;
- список городов;
- ключи хранения.

Пример сущностей:

| Поле | Назначение |
|---|---|
| `brand.name` | Название сайта |
| `brand.subtitle` | Подзаголовок |
| `brand.logo` | Логотип |
| `defaultUser.name` | Имя пользователя |
| `cities` | Города |
| `storageKeys.lastView` | Ключ последнего вида |

## 3. Застройщики

Файл: `js/data/developers.js`

Основная переменная: `window.KLIPER_DEVELOPERS`.

Поля:

| Поле | Назначение |
|---|---|
| `id` | Уникальный идентификатор |
| `name` | Название компании |
| `slug` | URL/служебное имя |
| `bgImage` | Обложка |
| `avatar` | Аватар/логотип |
| `districts` | Районы |
| `activeJK` | Количество строящихся ЖК |
| `builtJK` | Количество отстроенных ЖК |
| `likes` | Базовое количество лайков |
| `notifications` | Счетчик уведомлений |
| `comments` | Счетчик комментариев |
| `site` | Сайт компании, если задан |

Используется в каталоге застройщиков, больших страницах компаний, stories и профильных списках.

## 4. ЖК и новостройки

Файл: `js/data/buildings.js`

Основная переменная: `window.KLIPER_BUILDINGS`.

Поля:

| Поле | Назначение |
|---|---|
| `id` | Уникальный идентификатор |
| `name` | Название ЖК |
| `developer` | Застройщик |
| `district` | Район |
| `zone` | Тип расположения: город, вода, за городом |
| `status` | Статус: строится, уточнить и т.п. |
| `year` | Год сдачи |
| `price` | Цена |
| `imageUrl` | Изображение карточки |
| `tags` | Теги для фильтрации и сценариев |

Дополнительные обложки лежат в `js/data/jk-covers.js`.

## 5. Бизнес-помещения

Файл: `js/data/business-spaces.js`

Основная переменная: `window.KLIPER_BUSINESS_SPACES`.

Поля:

| Поле | Назначение |
|---|---|
| `id` | Идентификатор помещения |
| `title` | Название |
| `deal` | Аренда/продажа |
| `type` | Тип помещения |
| `district` | Район/зона |
| `address` | Адрес |
| `area` | Площадь |
| `floor` | Этаж |
| `price` | Цена |
| `pricePerMeter` | Цена за метр |
| `deposit` | Депозит/условия |
| `tax` | Налоги/комментарий |
| `image` | Главное изображение |
| `gallery` | Галерея |
| `badges` | Быстрые теги |
| `traffic` | Трафик |
| `ceiling` | Высота потолка |
| `power` | Мощность |
| `parking` | Парковка |
| `access` | Доступ |
| `condition` | Состояние |
| `payback` | Сценарий окупаемости/назначение |
| `description` | Описание |
| `owner` | Владелец/отдел |
| `phone` | Телефон |

## 6. Районы

Файлы:

- `js/data/tyumen-districts.js`
- `js/data/tyumen-districts.json`

Используются для карточек районов и подписки на район. Страница районов есть в коде, но в текущей v1-навигации частично скрыта.

## 7. Истории

Файл: `js/data/stories.js`

Основная переменная: `window.KLIPER_STORIES`.

Поля:

| Поле | Назначение |
|---|---|
| `name` | Название истории/компании |
| `image` | Изображение |
| `developerId` | Связь с застройщиком |

Также истории генерируются внутри основного приложения для карточек, профиля и топа.

## 8. Фильтры

Файл: `js/data/filters.js`

Основная переменная: `window.KLIPER_FILTERS`.

Поля:

| Поле | Назначение |
|---|---|
| `zones` | Зоны/районы |
| `novostroykiFilters` | Фильтры новостроек |
| `businessFormats` | Типы бизнеса |
| `businessTags` | Бизнес-теги |
| `businessParams` | Бизнес-параметры |

## 9. Локальные пользовательские данные

Хранятся в браузере пользователя:

| Ключ | Что хранит |
|---|---|
| `kliper-liked-cards` | Список лайкнутых карточек |
| `kliper-card-reviews` | Рецензии |
| `kliper-subscribed-cards` | Подписанные карточки |
| `kliper-subscribed-districts` | Подписанные районы |
| `kliper-theme` | Тема |

Реальной синхронизации между пользователями нет.
