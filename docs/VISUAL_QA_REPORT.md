## Найденные дефекты

### C-001: list-view теряет переключатели вида

Статус: closed / P1.

Сценарий:

1. Открыть `Новостройки`.
2. Нажать `view-list`.
3. Проверить строку `142 карточки`.

Старый факт:

- кнопки `Показать карточки сеткой`, `Показать карточки списком`, `Показать объекты на карте`, `Показать рейтинг с конца списка` исчезают из DOM;
- повторный клик по `Новостройки` не возвращает grid-controls;
- переход `Готовые ЖК -> Новостройки` в той же SPA-сессии также не возвращает controls.

Решение:

- добавлен `js/filters/residential-view-controls-guard.js`;
- guard запоминает штатные React handlers view-controls до перехода в list-view;
- если legacy list-view убрал controls, guard восстанавливает кнопки в строке счетчика;
- `list -> grid -> list -> map` работает без перезагрузки и без правки `js/app.js`.

Остаточный риск:

- это защитный post-render слой поверх legacy render state;
- при будущем переносе view-state из `js/app.js` guard можно удалить.

Проверено:

- `Новостройки -> list`: controls остаются доступны;
- `list -> grid -> list -> map`: переключение работает;
- horizontal overflow `0`;
- console/pageerror не найдено.

### C-002: list-view DOM содержит 143 карточки, но 142 видимые

Статус: accepted / monitored.

Факт:

- hidden legacy leak `Тюменский квартал` остается в DOM;
- пользовательский счетчик и видимые карточки: `142`;
- автотесты должны считать видимые карточки, а не все `[aria-label^="Открыть карточку"]`.

Рекомендация:

- не удалять элемент из DOM до app-level исправления данных;
- в тестах использовать visible count.
