# Шаблон задачи для чата

Используй этот шаблон перед любой правкой.

```text
Зона:
Ответственный чат:

Цель:

Что сейчас не так:

Можно менять:
- 

Нельзя менять:
-

Файлы-кандидаты:
-

Проверить после:
-

Ожидаемый результат:

Что считается ошибкой:

Нужен ли владелец:
нет / да, вопрос:
```

## Пример

```text
Зона: Filters System
Ответственный чат: Filters System

Цель:
Исправить цвет selected tags в темной теме.

Что сейчас не так:
Теги в панели после счетчика выглядят светлыми и выбиваются из dark theme.

Можно менять:
- css/ui-ux-pro-max.css
- js/filters/selected-filter-inline.js, если без JS нельзя

Нельзя менять:
- js/app.js
- карточки
- stories

Проверить после:
- новостройки
- готовые ЖК
- бизнес
- desktop
- mobile
- dark theme

Ожидаемый результат:
Selected tags читаются в темной теме и не ломают счетчик.

Что считается ошибкой:
Фильтр перестал сбрасываться или теги ушли на отдельную строку без причины.

Нужен ли владелец:
нет
```
